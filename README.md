# 🛡️ Angel Garden - Women's Safety Web App

**Angel Garden** is a comprehensive digital sanctuary designed to empower women with real-time security tools and community-driven safety features. This web application bridges the gap between technology and personal safety, providing users with a reliable platform to navigate their surroundings with confidence.

---

## 🚀 Key Features

* **One-Tap SOS:** Instant emergency triggers to notify trusted contacts or authorities.
* **Live Location Sharing:** Real-time GPS integration for secure transit monitoring.
* **Safety Map:** Interactive visualization of safe zones and community-verified routes.
* **Emergency Directory:** Quick-access database for nearby hospitals, police stations, and support centers.
* **Modern UI/UX:** A responsive, user-centric interface featuring glassmorphism and smooth interactive animations.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3 (Modern UI Frameworks), JavaScript
* **Backend:** Python (Flask Framework)
* **Database:** MySQL / Google Sheets API
* **APIs:** Google Maps Platform (Location Services), Twilio (SMS Alerts)
